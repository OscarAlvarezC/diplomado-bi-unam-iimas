# Bloque 04: SQL avanzado y PL/pgSQL

## :dart: Objetivo

Ejecutar consultas avanzadas en SQL y PL/pgSQL utilizando funciones agregadas, de carácter, de fecha, estructuras de control, cursores, procedimientos y funciones almacenadas.

## :clock1: Duración

7 horas.

## :pushpin: Temas

- **Funciones predefinidas en SQL:**
  - Agregadas: `count`, `sum`, `avg`, `min`, `max`.
  - Carácter: manipulación de strings (`upper`, `lower`, `substring`, `position`, `concat`, etc.).
  - Fecha: `date_trunc`, `extract`, `age`, `interval`, aritmética con fechas.
- **Estructuras de control en PL/pgSQL:**
  - `IF-THEN-ELSE-END IF`.
  - `CASE` (expresión y sentencia).
  - Ciclos `FOR` y `WHILE`.
- **Cursores:**
  - Declaración, apertura, fetch, cierre.
  - Cuándo usarlos vs queries set-based.
- **Procedimientos almacenados:**
  - Declaración de variables.
  - `CREATE PROCEDURE`.
  - Ejecución (`CALL`).
  - Eliminación (`DROP`).
- **Funciones definidas por el usuario:**
  - `CREATE FUNCTION` con `RETURNS`.
  - Funciones que devuelven escalares vs sets.
  - Diferencias prácticas función vs procedimiento.

Todos los temas se ejercitan sobre el data warehouse de Northwind construido en el Bloque 2.
