# Bloque 07: Caso integrador

## :dart: Objetivo

Integrar los conceptos de OLAP, ETL y SQL avanzado en un caso práctico de inteligencia de negocios, generando reportes descriptivos y consultas analíticas de valor empresarial.

## :clock1: Duración

2.5 horas.

## :pushpin: Temas

- **Pipeline ETL completo en Python** que tome datos crudos y los cargue al esquema estrella.
- **Consultas analíticas avanzadas** sobre el warehouse, integrando lo aprendido en bloques previos:
  - Al menos una **función de ventana** (Bloque 5).
  - Al menos una **CTE recursiva** (Bloque 5).
  - Al menos una **consulta sobre datos semiestructurados** con JSONB (Bloque 6).
- **Reporte descriptivo** que comunique los hallazgos a una audiencia no técnica.
- **Presentación final** de los resultados.

## :books: Entrega

Cada alumno entrega:

1. Script `etl_pipeline.py` ejecutable de extremo a extremo (del Bloque 3, eventualmente refinado).
2. Cuaderno (`.sql` o `.ipynb`) con las consultas analíticas requeridas.
3. Presentación corta de hallazgos.
